# Enzyme_Metadynamics_Scripts

Scripts for an enzyme QM/MM metadynamics workflow on the 5EJ5 system (ThDP-dependent
carboligase): build solvated systems, run classical equilibration MD, then run
well-tempered metadynamics on a cluster model with a machine-learned (UMA/FAIRChem)
potential driven through ASE + PLUMED.

This repository contains **scripts and small example inputs only** — large AMBER
topologies, trajectories, and PLUMED output (HILLS/COLVAR/grids) are intentionally
excluded (see `.gitignore`) and are regenerated by running the pipeline.

## Layout

```
prep_systems/     Build solvated systems from a receptor template + substrate library
classical_md/     AMBER classical MD (min → heat → density → equilibration, MMPBSA)
metadynamics/     ASE+PLUMED+UMA metadynamics driver + PMF/COLVAR analysis
```

### `prep_systems/`
QM/MM geometry + system preparation pipeline. Run the numbered scripts in order
(edit `python_job.sh`, which lists them, to toggle stages):

| Stage | DMC (first half) | AMC (second half) |
|-------|------------------|-------------------|
| generate placed system + ligand FF | `01_generate_DMC_for_MD.py` | `04_generate_hetero_AMC_for_MD.py` |
| pick active/cluster residues from MD | `02_get_active_DMC_residues.py` | `05_get_active_AMC_residues.py` |
| build cluster model + MTD inputs | `03_prepare_DMC_from_MD.py` | `06_prepare_AMC_from_MD.py` |

Supporting content (all bundled, referenced relative to the script directory):
- `utils.py` — shared geometry/MDAnalysis helpers.
- `scripts/` — helper shell scripts (`generate_don_ff.sh`, `assemble_{DMC,AMC}_for_MD.sh`,
  `format_MD.sh`) and tleap inputs (`tleap_{DMC,AMC}_md_script_updated.in`).
- `5EJ5/` — receptor templates (`5EJ5_DMC_receptor_updated.pdb`, `AMC_receptor_template_updated.pdb`).
- `substrates_initial/` — clean substrate geometries (`0.pdb`–`19.pdb`).
- `run_templates/{DMC,AMC}/` — AMBER MD input templates copied into each new run by the
  assemble scripts.

### `classical_md/`
The AMBER classical-MD stage (example: 5EJ5 DMC substrate 6).
- `run/` — submission scripts (`gpu_amber_job.sh`, `gpu_amber_continue.sh`, `run_all.sh`,
  `amber_min.sh`, `amber_mmgbsa.sh`) and input configs (`min.in`, `heat.in`,
  `density_05.in`, `density_10.in`, `equil.in`, `equil2.in`, `mmgbsa.in`, `cpptraj.in`).
- `prep/` — small ligand/cofactor force-field files (`DON.*`, `TPP.*`, `sqm.in`).

Workflow: minimize → heat (0→300 K) → density equilibration → NPT production →
MM-GBSA. `run_all.sh` chains the SLURM jobs. (This is an instantiated copy of
`prep_systems/run_templates/DMC/` plus `equil2.in`/`cpptraj.in`.)

### `metadynamics/`
- `run/md_uma_plumed.py` — main driver. Heating → equilibration → well-tempered MTD on
  a cluster model using the UMA (`uma-s-1p2`) potential in ASE, biased via PLUMED on the
  forming C–C bond (collective variable `d1`). Supports restart from `mtd_restart.traj`.
  Key knobs live near the top of the file: CV atom indices (PLUMED 1-based `445,680`),
  wall positions/force constants, MTD `SIGMA/HEIGHT/PACE/BIASFACTOR`, grid, and the
  water-confinement sphere.
- `run/submit_md_uma_plumed.sh` — SLURM GPU submission wrapper.
- `run/example_inputs/` — starting structures (`protonated_cluster.pdb`,
  `initial_cluster.pdb`, `active_region.pdb`).
- `analysis/` — post-processing:
  - `plot_pmf.py` — runs PLUMED `sum_hills` on `HILLS`, reconstructs the PMF, and plots
    convergence (safe to run on a live job — reads `HILLS` only).
  - `plot_colvar.py` — stitches/plots `COLVAR` time series across MTD restarts.
  - `MD_Analysis.py` + `MD_utils.py` — RMSD/RMSF analysis (MDAnalysis).
  - `every_nth_frame.py` — decimate large XYZ trajectories.
  - `python_job.sh` — SLURM wrapper for the RMSD analysis.

## Environment / paths to edit

These scripts were written for the Northwestern Quest cluster and carry site-specific
settings you will need to change for your environment:

- **Conda envs** in the `*.sh` scripts: prep/MD use
  `/home/gbf4422/Downloads/miniconda3/envs/jupyter-md-env`; metadynamics uses the UMA env
  (`/projects/p30041/gbf4422/envs/uma-env`).
- **SLURM**: account `p30041` and partitions in every `#SBATCH` header / submit script.
- **Output/data roots** hardcoded in the prep scripts: `head_dir` / `HEAD_DIR` /
  `MD_HEAD_DIR` (e.g. `/projects/p30041/gbf4422/5EJ5/MD_Final/{DMC,AMC}/`) and
  `OUTPUT_DIR` (`.../Metadynamics_Clusters/...`). These point at your working data tree,
  not this repo — repoint them before running.
- **Software**: AMBER (`pmemd.cuda`, `tleap`, `cpptraj`, `antechamber`, `parmchk2`),
  PLUMED, ASE, and FAIRChem/UMA must be installed and on `PATH`.

Bundled-dependency paths (helper scripts, tleap inputs, receptor templates, substrate
library, run templates) are resolved **relative to the script location**, so the pipeline
is self-contained once the environment settings above are adjusted.
